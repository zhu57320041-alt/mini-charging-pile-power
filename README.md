# mini 充电桩（电源版）

小功率充电桩的电源模块设计，交流输入，400 V 中间母线，后级 DAB 支持 300–750 V 可调输出。主控为 TI C2000 系列 `TMS320F280025C`，使用**立创 EDA 专业版**绘制，原理图共 3 页。

---

## ⚠️ 使用须知（请先读）

本项目是**学习用设计稿，不是可用的产品方案**：

1. **辅助电源电路为示意性画法，未做原理验证与实测，不可直接使用。** 它仅用于补全供电结构，不能作为设计依据。
2. **PCB 布局未经打板验证**，本仓库不提供 Gerber、BOM 等生产文件，请勿据此投产。
3. 原理图中的参数（阻容值、电感量、变压器匝比）仅供参考，未经完整计算与实测校核。
4. 400 V 属危险电压，调试需具备相应防护条件。

---

## 设计来源

- **前级 PFC 与 ACDC 级参考安森美（onsemi）官方推荐应用设计**。本项目选用 onsemi 器件（主功率级为 `NCP58921MNTWG` GaN 功率级），因此直接以其数据手册中的典型应用电路为起点，再按本项目的输入输出要求调整。
- 保护电路、EMI 滤波参考通用电源设计规范。
- 后级 DC-DC、控制与通信部分为自行设计。

---

## 电路组成

### 第 1 页 · 前级（AC → 400 V）

| 区块 | 内容 |
| --- | --- |
| 保护电路 | 输入保险、压敏电阻、防浪涌与过流保护 |
| EMI 电路 | 共模电感与 X/Y 电容构成的输入滤波 |
| 全向 PFC + LLV 电路 | 功率因数校正级，`NCP58921MNTWG` GaN 功率级（图中标注名称） |
| ACDC 电路 | 隔离变换级，`NCP58921MNTWG` 功率级 |
| 400 V 输出 | 中间母线输出 |

### 第 2 页 · DC-DC 与控制

| 区块 | 内容 |
| --- | --- |
| 8 相交错并联 Boost | `VCU_LLC` 升压至 `VMM`，8 路电感交错工作 |
| DAB 调制电路 | 双有源桥，全桥 + 高频变压器 + 副边整流，**支持 300–750 V 可调输出** |
| 控制电路 | `TMS320F280025C`（C2000），PWM、ADC、比较器与保护输入 |
| 隔离驱动电路 | 14 路隔离栅极驱动，覆盖 PFC、Boost、DAB 各级开关管 |
| 电压采样电路 | `VOUT`、`VCU_LLC`、`NET1` 等节点的分压采样与滤波 |

### 第 3 页 · 辅助电源与通信

| 区块 | 内容 |
| --- | --- |
| 辅助电源电路 | 反激拓扑，输出 3V3、5V、+15V3；TL431 + 光耦反馈。⚠️ **未验证，不可使用** |
| CAN 通信电路 | CAN 收发器与对外接口（`CANH` / `CANL` / `GND`），接 MCU 的 `GPIO26` / `GPIO27` |
